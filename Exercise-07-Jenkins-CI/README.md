\# Exercise 7: Introduction to CI and Jenkins Installation



\## Objective

Understand Continuous Integration (CI), its benefits and workflow, and install Jenkins using Docker.



\## What is Continuous Integration?

Continuous Integration is a development practice in which developers frequently integrate code changes into a shared repository. Automated builds and tests help detect problems early and provide quick feedback.



\## Key Features of CI

\- Frequent code integration

\- Automated builds

\- Automated testing

\- Immediate feedback



\## Benefits of CI

\- Early bug detection

\- Improved collaboration

\- Faster development cycles

\- Higher software quality



\## Jenkins

Jenkins is an open-source automation server used to automate software building, testing, and delivery.



Key concepts include jobs, builds, pipelines, plugins, and nodes.



\## Installation

Jenkins was installed using Docker with ports 8080 and 50000 exposed and a persistent volume for Jenkins data.



\## Verification

\- Jenkins container started successfully.

\- Jenkins initial administrator setup was completed.

\- Jenkins dashboard is accessible at http://localhost:8080.

\- Jenkins is ready for creating jobs and pipelines.
